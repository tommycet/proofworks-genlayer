# Contributing to ProofWorks GenLayer

Welcome to ProofWorks GenLayer! We appreciate your interest in contributing to our project. Please follow the guidelines below to get started.

## Setup
To set up the development environment:
1. Fork the repository and clone your fork locally.
2. Install the necessary dependencies as outlined in the project's documentation.
3. Ensure your local environment is configured correctly before starting development.

## Running the tests
Before submitting any changes, you must ensure that all tests pass. This helps maintain the stability and reliability of the project.
You can execute the test suite by running the following command:
`make test`

## Submitting a pull request
When you are ready to submit your changes, please follow these steps:
1. Create a new branch for your feature or bug fix (`git checkout -b feature/your-feature-name`).
2. Commit your changes with clear and descriptive commit messages.
3. Push your branch to your forked repository on GitHub (`git push origin feature/your-feature-name`).
4. Open a Pull Request against the `main` branch of the original `tommycet/proofworks-genlayer` repository.
5. Provide a clear description of the changes you've made and reference any related issues.
