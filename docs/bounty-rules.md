# Bounty Rules

ProofWorks routes bounty work through escrow so creators, workers, and jurors can settle disputed work with predictable rules.

## Appeal Fees

- A party that appeals an AI jury verdict must post an appeal bond.
- The appeal bond is 20% of the task reward.
- The bond discourages frivolous appeals while still giving either side a path to challenge an incorrect verdict.
- Once an appeal is opened, designated jurors vote on the outcome before the task can be finalized.

## Worker Staking

- A creator can require a worker stake when creating a task.
- The required stake is calculated as a percentage of the task reward and is paid when the worker claims the task.
- The stake remains locked while the claim is active.
- If the claim expires without a proof submission, the worker stake is forfeited.
- Releasing an expired claim returns the task to the open pool so another worker can claim it.

## Finalization

- Approved work pays the worker.
- Rejected work refunds the creator.
- Partial verdicts split the reward according to the stored payout percentage.
- Tasks that need revision must be resubmitted and evaluated again before payout can be finalized.
